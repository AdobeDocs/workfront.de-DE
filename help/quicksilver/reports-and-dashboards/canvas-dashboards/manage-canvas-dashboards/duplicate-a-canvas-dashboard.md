## Voraussetzungen

Sie müssen ein Dashboard erstellen, bevor es dupliziert werden kann.

Weitere Informationen finden Sie unter [Erstellen eines Arbeitsflächen-Dashboards](/help/quicksilver/reports-and-dashboards/canvas-dashboards/create-dashboards/create-dashboards.md).

## Kopieren eines Dashboards

>[!NOTE]
>
>Freigabeeinstellungen werden nicht in das neue Dashboard kopiert. Wenn ein Widget eine **Als Benutzer ausführen**-Konfiguration hat, wird diese Konfiguration nur dann auf der Kopie beibehalten, wenn Sie der vorgesehene Benutzer oder Systemadministrator sind.

So kopieren Sie ein Dashboard:

{{step1-to-dashboards}}

1. Klicken Sie im linken Bedienfeld auf **Arbeitsflächen-Dashboards**.

1. Öffnen Sie auf **Seite** Arbeitsflächen-Dashboards“ das Dashboard, das Sie kopieren möchten.

1. Klicken Sie oben rechts auf das Symbol **Mehr** ![Mehr](assets/more-icon.png) und dann auf **Kopieren**.
   ![Menüoption „Dashboard kopieren“](assets/duplicate-dashboard.png)

1. Geben Sie im Dialogfeld **Dashboard kopieren** einen **Namen** für das neue Dashboard ein, der standardmäßig auf den Namen des Quell-Dashboards gefolgt von „(Kopieren)“ verweist.

1. (Optional) Aktualisieren Sie auf der **Dashboard-**&quot; die **Beschreibung** oder **Währung** für das neue Dashboard.
   ![Dashboard kopieren - Registerkarte „Dashboard-Details“](assets/duplicate-details.png)

1. (Optional) Klicken Sie auf die **Widgets** und heben Sie dann die Auswahl für alle Widgets auf, die Sie nicht in das doppelte Dashboard aufnehmen möchten.
   ![Dashboard kopieren - Registerkarte „Widgets“](assets/copy-widgets.png)

1. (Optional) Klicken Sie auf die **Filter und Eingabeaufforderungen** und deaktivieren Sie dann **Dashboard-Filter kopieren** oder **Dashboard-Eingabeaufforderungen kopieren**, um sie aus dem doppelten Dashboard auszuschließen.
   ![Dashboard kopieren - Registerkarte „Filter und Eingabeaufforderungen“](assets/copy-filters.png)

1. Klicken Sie **Dashboard kopieren**.

Es wird eine Bestätigungsmeldung mit einem Link zum neuen Dashboard angezeigt.
