# Genehmigungsvorlagen verwalten

Nachdem Sie eine Validierungsvorlage erstellt haben, können Sie sie bearbeiten, freigeben oder löschen. Systemadministratoren können auch jede Vorlage im Konto bearbeiten, löschen und stapelweise löschen, unabhängig davon, wer sie erstellt oder freigegeben hat.

>[!IMPORTANT]
>
>Der Inhalt dieses Artikels bezieht sich auf aktualisierte Dokumentgenehmigungsfunktionen, die nur für bestimmte Konten verfügbar sind. Informationen zu standardmäßigen Genehmigungsprozessen finden Sie in den Artikeln, die unter [Arbeitsgenehmigungen“ aufgeführt ](/help/quicksilver/review-and-approve-work/manage-approvals/manage-approvals.md).

## Bearbeiten einer Vorlage

So bearbeiten Sie eine Vorlage:

1. Klicken Sie im linken Bereich auf **Überprüfen und**) > **Genehmigungsvorlagen**.
1. Aktivieren Sie das Kontrollkästchen neben der Vorlage, die Sie bearbeiten möchten. Unten auf der Seite wird eine Leiste angezeigt.
1. Klicken Sie in der Leiste auf **Bearbeiten**.
1. Aktualisieren Sie die Vorlage nach Bedarf.
1. Klicken Sie auf **Speichern**.

Sie können die von Ihnen erstellten Vorlagen bearbeiten. Systemadministratoren können jede Vorlage im Konto bearbeiten, unabhängig davon, wer sie erstellt hat.

## Freigeben einer Vorlage

Standardmäßig ist eine Vorlage nur für Sie als Ersteller sichtbar. Sie können sie für bestimmte Benutzer oder für alle Personen in Ihrer Organisation freigeben, damit diese sie bei der Anforderung einer Genehmigung anzeigen und verwenden können.

Freigeben einer Vorlage:

1. Klicken Sie im linken Bereich auf **Überprüfen und**) > **Genehmigungsvorlagen**.
1. Aktivieren Sie das Kontrollkästchen neben der Vorlage, die Sie freigeben möchten. Unten auf der Seite wird eine Leiste angezeigt.
1. Klicken Sie in der Leiste auf &quot;**&quot;**. Das **Freigabegenehmigungsvorlage** wird geöffnet.
1. Klicken Sie auf die Dropdown-Liste Freigabe und wählen Sie dann eine der folgenden Optionen:

   <table>
   <tr>
   <td><strong>Freigegeben für alle</strong></td>
   <td>Alle Benutzer in Ihrer Organisation können die Vorlage anzeigen und verwenden.</td>
   </tr>
   <tr>
   <td><strong>Nur eingeladene Personen haben Zugriff</strong></td>
   <td>Nur Sie und die von Ihnen hinzugefügten Benutzer können die Vorlage anzeigen und verwenden. Dies ist der Standard für neue Vorlagen.</td>
   </tr>
   </table>

1. Wenn Sie **Nur eingeladene Personen können zugreifen** unter **Zugriff auf Genehmigungsvorlage erteilen** ausgewählt haben, verwenden Sie das Feld **Nach Personen suchen**, um die Benutzer hinzuzufügen, denen Sie Zugriff erteilen möchten.
1. Klicken Sie auf **Freigabe**.

Die Spalte **Freigegeben für** in der Liste der Genehmigungsvorlagen zeigt an, wer Zugriff auf jede Vorlage hat. Sie werden immer als Ersteller der Vorlage aufgeführt und können nicht entfernt werden.

## Löschen einer Vorlage

Sie können eine von Ihnen erstellte Vorlage löschen. Systemadministratoren können alle Vorlagen im Konto löschen oder stapelweise löschen, einschließlich Vorlagen, die von anderen Systemadministratoren erstellt wurden, unabhängig von den Freigabeeinstellungen.

Löschen einer oder mehrerer Vorlagen:

1. Klicken Sie im linken Bereich auf **Überprüfen und**) > **Genehmigungsvorlagen**.
1. Aktivieren Sie das Kontrollkästchen neben einer oder mehreren Vorlagen.
1. Klicken Sie in der Leiste unten auf der Seite auf **Löschen** und bestätigen Sie dann den Löschvorgang.

>[!WARNING]
>
>Das Löschen einer Vorlage ist dauerhaft. Wenn Sie Systemadministrator sind, kann Ihre Auswahl Vorlagen enthalten, deren Inhaber Sie nicht sind. Überprüfen Sie die Liste sorgfältig, bevor Sie sie bestätigen, insbesondere wenn Sie mehrere Vorlagen gleichzeitig löschen.
