# Übersicht über Adobe Creative Cloud-Projekte

Sie können direkt über Adobe Photoshop, Illustrator und InDesign auf Ihre Workfront-Projekte zugreifen. Im Bedienfeld Projekte auf der linken Seite im Fenster der Creative Cloud-App können Sie Dokumente in einem Workfront-Projekt öffnen, bearbeiten und speichern, ohne die App verlassen zu müssen. Sie können neue Dateien auch direkt in einem Workfront-Projekt speichern.

Nur Projekte, die den Adobe-Cloud-Speicher verwenden, werden im Bedienfeld „Projekte“ neben Ihren anderen Creative Cloud-Projekten angezeigt. Das Bedienfeld spiegelt die Ordnerstruktur der Dokumente in Workfront wider.

Wenn Sie ein Dokument mit einem Genehmigungs-Workflow speichern, erstellt Workfront eine neue Version und behält den Genehmigungsverlauf bei. Wenn Sie ein Dokument speichern, das keinen Genehmigungs-Workflow hat, aktualisiert Workfront die neueste Version.

## Voraussetzungen

* Ihr Unternehmen muss über eine Version von Workfront verfügen, die die Adobe-Cloud-Datenspeicherung unterstützt.
* Workfront und Photoshop, Illustrator oder InDesign müssen Berechtigungen in derselben Adobe Identity Management System (IMS)-Organisation haben.


## Was Sie über das Bedienfeld Projekte in Photoshop, Illustrator oder InDesign tun können

* Öffnen Sie Workfront-Projektordner und -Dokumente direkt in Photoshop, Illustrator oder InDesign. Jedes Workfront-Projekt, auf das Sie Zugriff haben, wird im Bedienfeld Projekte angezeigt.
* Bearbeiten Sie eine Datei und speichern Sie Ihre Änderungen wieder im Workfront-Projekt.

Weitere Informationen finden Sie unter [Verwenden von Workfront-Dokumenten in Creative Cloud-Programmen](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md).

>[!NOTE]
>
>Ältere Workfront-Speicherprojekte werden im Bedienfeld „Projekte“ nicht unterstützt.

## Verwandte Integrationen

Sie können mit dem Adobe Cloud Drive auch Workfront-Dateien verwalten und Ihre Änderungen an Dokumenten in Workfront automatisch speichern. Weitere Informationen finden Sie unter [Übersicht über Adobe Cloud Drive](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md).
