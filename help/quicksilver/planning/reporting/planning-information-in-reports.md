# Workfront-Planungsinformationen in Berichten anzeigen

Sie können Adobe Workfront-Planungsinformationen in Berichten anzeigen, wenn Sie das Arbeitsflächen-Dashboard verwenden.

>[!IMPORTANT]
>
>Die Funktion Canvas-Dashboards ist derzeit nur für Benutzer verfügbar, die an der Beta-Phase teilnehmen. Teile der Funktion sind in dieser Phase möglicherweise nicht vollständig oder funktionieren nicht wie vorgesehen.
>Die Beta-Version ist bei den folgenden Cloud-Anbietern nicht verfügbar:
>
>* Eigene Schlüssel für Amazon Web Services mitbringen
>* Azure
>* Google Cloud Platform
> Weitere Informationen finden Sie unter [Verwalten von Canvas-Dashboards: Artikel-Index](/help/quicksilver/reports-and-dashboards/canvas-dashboards/manage-canvas-dashboards/manage-canvas-dashboards.md).

## Planungsinformationen in Arbeitsflächen-Dashboards anzeigen
