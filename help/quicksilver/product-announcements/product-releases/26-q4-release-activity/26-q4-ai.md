## Neues Tool „Benutzer suchen“ im Workfront MCP-Connector verfügbar

>[!NOTE]
>
>Produktion: 13. August 2026

Damit Sie Personen schneller in Ihrer Workfront-Instanz finden können, haben wir ein neues Tool zum Workfront MCP-Connector hinzugefügt:

* Benutzer suchen

Geben Sie einen vollständigen oder teilweisen Namen in das Tool „Benutzer suchen“ ein, um wieder die passenden Benutzer zu finden. Sie können auch KI-Collaborator-„Bots“ neben regulären Benutzern in die Ergebnisse aufnehmen.

Im Rahmen dieser Änderung wurden die folgenden Tools eingestellt:

* Dokument suchen
* Suchen von Projekten
* Team nach Namen suchen
* Benutzer nach Namen suchen
* Aktuellen Benutzer abrufen
* Dokumente nach Umfang abrufen

Wenn Sie Workflows haben, die diese Tools verwenden, aktualisieren Sie diese, sodass sie stattdessen die Tools „ID nach Name suchen“, &quot;Workfront-Daten suchen“ oder „Benutzer suchen“ verwenden.

Weitere Informationen finden Sie unter [Adobe Workfront MCP-Server-Tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Senden von Assets an Adobe Experience Manager und Hinzufügen benutzerdefinierter Nachrichten für Genehmigungen mithilfe des Workfront MCP-Servers

>[!NOTE]
>
>Vorschau: 12. August 2026
>Produktion: 12. August 2026

Um die Funktionen des Workfront MCP-Connectors zu erweitern, haben wir die folgenden Tools hinzugefügt:

* Senden Sie Dokumente an einen mit AEM verknüpften Ordner und listen Sie die mit AEM verknüpften Ordner auf, die in einem Projekt verfügbar sind.
* Fordern Sie eine Genehmigung für eine Dokumentversion mit einer benutzerdefinierten Nachricht zusammen mit dem Titel, den genehmigenden Personen oder Prüfenden und einem optionalen Fälligkeitsdatum an.

Weitere Informationen finden Sie unter [Adobe Workfront MCP-Server-Tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Zuweisen von KI-Aufgabenmitarbeitern zu Aufgaben in Workfront

>[!NOTE]
>
>Vorschau: 31. Juli 2026
>Produktions-Schnellveröffentlichung: 13. August 2026
>Produktion für alle: 13. August 2026

Damit Sie Ihre KI-Agenten für die Arbeit in Workfront verwenden können, haben wir Aufgabenmitarbeiter erstellt. Aufgabenmitarbeiter sind KI-Mitwirkende, die zusätzlich zu dem bestehenden KI-Mitwirkenden des Typs „Prüfer“, der für Dokument- und Asset-Überprüfungen verwendet wird, direkt Workfront-Aufgaben zugewiesen werden können. Aufgabenmitarbeiter stellen eine Verbindung zu Agenten her, die Sie in Copilot Studio, Claude oder Writer konfiguriert haben, und weisen sie Aufgaben zu, genau wie Sie einen Benutzer zuweisen würden.

Weitere Informationen finden Sie unter [Konfigurieren von KI-Mitwirkenden](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).

## Neue Validierungstools im Workfront MCP Connector verfügbar

>[!NOTE]
>
>Vorschau: 30. Juli 2026
>Produktions-Schnellveröffentlichung: 13. August 2026
>Produktion für alle: 15. Oktober 2026

Um die Funktionen des Workfront MCP-Connectors zu erweitern, haben wir die folgenden neuen Tools hinzugefügt:

* Pfad zur Genehmigung hinzufügen
* Pfad aus Genehmigung entfernen
* Schritt zum Pfad hinzufügen
* Stadium aus Pfad entfernen
* Stadien im Pfad neu anordnen

Außerdem wurden die folgenden Tools erweitert, um parallele Genehmigungspfade zu berücksichtigen:

* Informationen zum Genehmigungs-Workflow abrufen
* Genehmigungs-Workflow erstellen oder aktualisieren
* Genehmigung aus Vorlage erstellen

Weitere Informationen finden Sie unter [Adobe Workfront MCP-Server-Tools](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).
