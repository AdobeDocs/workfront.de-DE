# KI-Verbesserungen für das erste Quartal 2027

Auf dieser Seite werden KI-Verbesserungen beschrieben, die mit der Version vom ersten Quartal 2027 in der Vorschau-Umgebung vorgenommen wurden. Diese Verbesserungen werden wie angegeben in der Produktionsumgebung verfügbar gemacht.

Eine Liste aller Änderungen, die zu diesem Zeitpunkt im ersten Quartal 2027 verfügbar sind, finden Sie unter [Versionsübersicht 1. Quartal 2027](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Konfigurieren des vorgefertigten KI-Mitwirkenden-Koordinators

>[!NOTE]
>
>Vorschau: 22. November 2026
>Produktionsschnellveröffentlichung: 17. Dezember 2026
>Produktion für alle: 21. Januar 2027

Administratoren können jetzt den Aufnahmekoordinator, einen vordefinierten KI-Mitwirkenden, als Arbeitsagenten konfigurieren, indem sie Adobe Native als Herkunft des Agenten auswählen. Benutzer können dann den Arbeitsagenten einem Problem zuweisen, um dessen Details, benutzerdefinierte Formulare und Anhänge auf fehlende, unklare oder inkonsistente Informationen zu überprüfen. Der Aufnahmekoordinator sendet Feedback oder nimmt Änderungen mit Genehmigung des Benutzers vor.

Weitere Informationen finden Sie unter [Konfigurieren von vordefinierten KI-Mitwirkenden](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-prebuilt-ai-collaborators.md).

## Verwenden von Writer-Playbooks zum Erstellen von Arbeitsagenten

>[!NOTE]
>
>Vorschau: 12. November 2026
>Produktions-Schnellveröffentlichung: 12. November 2026
>Produktion für alle: 12. November 2026
>[!BADGE Gleichzeitige Veröffentlichung]{type=Neutral}

Sie können jetzt Writer-Playbooks verwenden, um Arbeitsagenten zu erstellen. Nachdem Sie ein Writer-Playbook als Arbeitsagent konfiguriert haben, können Sie es in Workfront Aufgaben zuweisen, genau wie Sie es einem Benutzer zuweisen würden.

Weitere Informationen finden Sie unter [Konfigurieren von KI-Mitwirkenden](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).

## Arbeitsagenten: Nativer Adobe-Support

>[!NOTE]
>
>Vorschau: 29. Oktober 2026
>Produktions-Schnellveröffentlichung: 12. November 2026
>Produktion für alle: 21. Januar 2027

Um das Einbringen von KI-gestützter Arbeit in Ihre Workflows zu erleichtern, haben wir Adobe Native als unterstützten Ursprung für Arbeitsagenten hinzugefügt.

Sie können jetzt einen Arbeitsagenten erstellen, der den CX Enterprise Coworker Collaborator verwendet, einen CX Enterprise Coworker-Agenten, der von Adobe Agent Orchestrator unterstützt wird, ohne eine separate externe Plattform zu konfigurieren oder externe Anmeldeinformationen einzugeben. Dadurch erhalten Teams einen schnelleren Einstieg, während sie dasselbe Workfront-Aufgabenzuweisungs- und -Ausführungsmodell beibehalten.

Das Setup-Erlebnis spiegelt jetzt auch die herkunftsbasierten Unterschiede zwischen nativen und externen Adobe-Agenten wider, einschließlich der Voraussetzungen und des Konfigurationsflusses für jede Option.

Native Agenten können einer Aufgabe mithilfe von @mention in den Kommentaren für die Aufgabe hinzugefügt werden.

Weitere Informationen finden Sie unter [Konfigurieren von KI-](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md) und [Verwenden von Arbeitsagenten](/help/quicksilver/manage-work/tasks/assign-tasks/use-task-collaborators.md).
