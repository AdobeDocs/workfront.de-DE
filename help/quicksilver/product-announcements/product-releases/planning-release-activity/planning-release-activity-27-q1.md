# Versionsaktivität für Adobe Workfront Planning im ersten Quartal 2027

In diesem Artikel werden die Funktionen beschrieben, die in der Version vom ersten Quartal 2027 für Workfront Planning veröffentlicht werden.

Eine Liste aller für Adobe Workfront Planning veröffentlichten Funktionen finden Sie unter [Adobe Workfront Planning Release-Aktivität: Artikelindex](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md).

## Standardmäßige Eingabeaufforderungseinstellungen für die Funktion „Formular ausfüllen“ in Planungsanfragen einrichten

>[!NOTE]
>
>Vorschau: 21. Oktober 2026
>Produktions-Schnellveröffentlichung: 12. November 2026
>Produktion für alle: 21. Januar 2027

Sie können jetzt die Eingabeaufforderung anpassen, die Benutzern angezeigt wird, wenn sie die KI-gestützte Formularausfüllfunktion beim Senden einer Planungsanfrage verwenden.

Sie können beim Erstellen eines Anforderungsformulars für Planning-Anforderungen eine Standardaufforderung erstellen.

Weitere Informationen finden Sie unter [Erstellen und Verwalten eines Anfrageformulars in Adobe Workfront Planning](/help/quicksilver/planning/requests/create-request-form.md).
